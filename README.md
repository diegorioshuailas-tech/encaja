# Encaja — muebles y deco que se prueban en tu casa

Prototipo de e-commerce con **probador por IA**: subís una foto de tu ambiente y probás sofás, lámparas encendidas, plantas y colores de pared o puerta en escala real, con validación de medidas antes de comprar.

Proyecto del **Laboratorio de Ideación de Nuevos Productos y Servicios — Grupo 2**.

## Qué incluye
- Tienda: inicio, categorías, ficha de producto con visor 3D, carrito y checkout de prueba (no procesa pagos).
- Probador: foto propia o ambientes de ejemplo, productos 3D y con foto real, luz de día/noche, lámparas encendidas (2700/3000/4000 K), pintura de paredes y puertas, y sello de medidas.

## Cómo verla
Es un sitio estático: `index.html` + carpeta `img/`. Se publica con GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).

> Fuera de Claude, el análisis de la foto usa el modo automático del navegador; el análisis con Claude y el panel de carga de productos sólo funcionan dentro de Claude.
