# Cauce · Baños y revestimientos

Prototipo del Laboratorio de Ideación · Grupo 2. **Cauce es una marca ficticia.**

Tienda de porcelanatos, revestimientos, griferías, sanitarios y pinturas con un **probador IA**. Elegís un ambiente vacío o subís una foto, tocás el piso o una pared y probás porcelanatos (con pastina, junta y colocación), revestimientos a media altura con pintura arriba, o pintura sola. Después sumás grifería, sanitarios y muebles en 3D. El probador mide los m² en la foto, suma 10 % de desperdicio para las cajas y calcula las latas de pintura.

## Cómo publicarla en GitHub Pages
1. Subí **todo el contenido de esta carpeta** al repositorio (incluida la carpeta `img`).
2. En *Settings → Pages*, elegí *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
3. En un par de minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

El análisis con Claude (asistente y lectura automática de la foto) sólo funciona cuando la página se abre como artefacto de Claude. En GitHub Pages el probador usa el análisis automático del navegador y las fotos de ejemplo calibradas: revestir, mover productos, calcular cajas y el carrito funcionan igual.
